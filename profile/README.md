## Open-Source Developer Tooling (`@GGGODLIN` · 360+ GitHub Stars)

Core open-source CLI tools, harnesses, and benchmarks authored and maintained by founder Philip Lin ([`@GGGODLIN`](https://github.com/GGGODLIN), preserved at their original repository URLs so existing CLI installs and package references never break):

- **[GGGODLIN/claude-pr-review](https://github.com/GGGODLIN/claude-pr-review)** (115★) — Multi-axis PR review orchestration for Claude Code with 5 independent review perspectives, cross-verification, and cross-round continuity reconciliation.
- **[GGGODLIN/cc-translate-proxy](https://github.com/GGGODLIN/cc-translate-proxy)** (102★) — Local sidecar translation proxy for Claude Code workflows.
- **[GGGODLIN/gggodlin-cc-harness](https://github.com/GGGODLIN/gggodlin-cc-harness)** (74★) — Deterministic governance layer for Claude Code: pre-tool gates, spec-to-ticket workflows, and contract verification.
- **[GGGODLIN/cc-mod-image-view](https://github.com/GGGODLIN/cc-mod-image-view)** (51★) — Inline pasted-image thumbnail mod for Claude Code.
- **[GGGODLIN/gaddi](https://github.com/GGGODLIN/gaddi)** (14★) — Mobile UI fork for terminal coding agents across Herdr, tmux, and zellij.
- **[GGGODLIN/cc-mod-park](https://github.com/GGGODLIN/cc-mod-park)** (13★) — Session park and resume mod for Claude Code.
- **[GGGODLIN/repo-to-bench](https://github.com/GGGODLIN/repo-to-bench)** — Turn real repository revisions into reproducible Harbor-backed coding-agent benchmarks.
